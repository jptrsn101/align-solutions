Southern North Sea
Case study / Oil & Gas

Criticality and critical spares on a North Sea gas platform.

A system-by-system criticality analysis that classes every tag C1 to C3 and decides which spares to hold, built to feed the maintenance review that follows.

The
challenge.

The operator needed to know which equipment on the platform really matters, and which spares to hold for it, before reviewing any maintenance.

A register you can defend

Criticality decides where maintenance hours, inspection and spares money go. If it's rated by feel, or every gauge on a safety system comes out C1, it drives the wrong work. The ratings needed a written reason for every tag, agreed with the people who run the plant.

Not a maintenance review, yet

This stage classes the equipment and sets the spares. The maintenance review comes next and uses these results, so the work is built on agreed criticality rather than habit.

The method

Six steps,
system by system.

  1. Step 01

    Review the system

    Walk the system with operations and maintenance from the P&IDs and cause and effect charts, so everyone agrees what it does before anything is scored.

  2. Step 02

    Break it into main functions

    A system can do several jobs. Each job is a main function, and only main functions get scored.

  3. Step 03

    Score each main function

    Ask what happens if the whole function is lost. Safety, environment and production are each scored 1 to 3. The worst score sets the class.

  4. Step 04

    Give each tag a sub function

    Every tag is assigned what it does for its main function: containment, shutdown, alarm, measurement and so on. A set rule turns that into its scores.

  5. Step 05

    Class, area and code

    Each tag ends up with a class from C1 to C3 and a safety or production area, combined into one code the maintenance review can sort on.

  6. Step 06

    Critical spares

    Spares inherit the class of the tag they fit. Rules on redundancy and lead time decide what is stocked, how many and where.

The analysis draws on NORSOK Z-008 for consequence classification and spares, adapted to UK practice with safety-critical element references. Steps 1 to 3 run once per system in workshops. Steps 4 to 6 run for every tag, by rule first, then reviewed by operations, maintenance, the technical authority and HSE.

Score the function,
not the system.

Score a wellhead system as one thing and every gauge on it comes out C1. So each well is split into two main functions. Containing the gas is a major hazard if it fails. Controlling the flow, if lost, only loses that well. Each function is scored as if there were no standby, and redundancy is recorded separately.

Redundancy

Recorded on every tag.
Safety gets no credit.

A

No standby. If it fails, the function is lost.

A single subsurface safety valve on a well

B

One standby. One unit can fail and the function carries on.

Duty and standby generators

C

Two or more standbys.

Three fire pumps, any one enough

Redundancy never lowers a class. Two shutdown valves on one function are both still C1. On production equipment it does count when deciding spares.

What the client gets.

  • A critical tag register: every tag classed C1 to C3, with area, code and a written reason
  • A critical spares register: class, category, stock or not, quantity and location for every spare
  • Override records with the reason and the name of who decided
  • A clean, agreed base for the maintenance review
Critical spares

Stocked by rule, not by habit.

Each spare takes the class of the tag it fits. C1 and C2 spares with no standby are stocked; C3 spares are ordered when needed. Quantities come from the PM programme, the number fitted and vendor recommendations. Any line can be overridden, with a reason.
